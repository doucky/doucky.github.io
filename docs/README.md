# doucky.github.io — Documentation

This folder contains the documentation for the blog. Two audiences, two guides.

| File | For | Contents |
|---|---|---|
| [user-guide.md](./user-guide.md) | **Content authors** | How to write and publish articles, add tags, add tools |
| [developer-guide.md](./developer-guide.md) | **Developers** | Project structure, CSS/JS architecture, how to extend the site |

---

## Quick start

```bash
# Install dependencies (once)
bundle install

# Run local dev server with live reload
bundle exec jekyll serve --livereload

# Open in browser
open http://localhost:4000
```

The site auto-rebuilds on every file save. No manual rebuild needed during development.
